

# Validador Siconfi (Client-Side)
Validador de obrigações contábeis e fiscais municipais integrado à API do Siconfi (Tesouro Nacional).

## Funcionalidades
1. Leitura de MSC (.csv) e XMLs do RREO, RGF e DCA.
2. Cruzamento automático de saldos orçamentários/patrimoniais.
3. Validação de regras da Dimensão 1 a 4.

## Deploy
Desenvolvido em React + Vite. Sem backend necessário.
Para subir no GitHub Pages:
```bash
npm run deploy
```
